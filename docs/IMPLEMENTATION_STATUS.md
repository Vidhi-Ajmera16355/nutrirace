## Known gaps and risks

- Rate limiting uses in-memory storage (single replica only).
- `eslint-plugin-jsx-a11y` (bundled with `eslint-config-next`) declares peer support up to ESLint 9; lint passes on ESLint 10 but pnpm prints an unmet-peer warning.
- Two deprecated transitive dev dependencies (`cron-parser`, `glob`) come in through NestJS tooling.
- The web app has no unit tests; behaviour is covered only by (unexecuted) Playwright tests.
- `SENTRY_DSN` and `AUTH_SECRET` are validated but not yet consumed.
- No dark theme; system font stack is used on purpose (no external font fetches).
